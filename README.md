# Приложение для управления лазерной подсветкой

Это приложение позволяет управлять лазерной подсветкой через TCP/IP или COM-порт интерфейс.

## Требования

- Python 3.6 или выше
- Библиотека PyQt5
- Библиотека pyserial

## Установка

1. Убедитесь, что у вас установлен Python
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Запуск приложения

Запустите приложение командой:
```
python laser_backlight.py
```

## Использование

1. Выберите тип подключения: TCP/IP или COM-порт
   - Для TCP/IP: укажите IP-адрес и порт
     - Адрес по умолчанию: 192.168.0.7
     - Порт по умолчанию: 20108
   - Для COM-порта: выберите порт из списка доступных и установите скорость передачи
   
2. Нажмите кнопку "Подключиться"

3. После подключения вы можете:
   - Включать/выключать лазер
   - Регулировать яркость
   - Устанавливать углы поворота
   - Запрашивать статус устройства
   - Изменять адрес устройства
   - Изменять скорость передачи данных

## Поддерживаемые функции

- Управление питанием лазера
- Регулировка яркости
- Управление углом поворота
- Запрос информации об устройстве
- Изменение сетевого адреса устройства
- Изменение скорости передачи данных (baud rate)
- Журнал обмена данными между приложением и устройством
- Выбор типа подключения: TCP/IP или COM-порт

## Устранение неполадок

### Превышено время ожидания ответа от устройства

Если вы получаете сообщение о превышении времени ожидания:
- Устройство может быть занято обработкой предыдущей команды
- Проверьте правильность сетевых настроек (IP-адрес и порт) или настройки COM-порта
- Команды управления (вкл/выкл, регулировка) могут не возвращать ответ сразу
- Запросные команды (статус, яркость, версия) требуют больше времени для получения ответа
- Убедитесь, что другое программное обеспечение не использует одновременно соединение с устройством

### Нет связи с устройством

- Проверьте сетевое подключение к устройству или подключение через COM-порт
- Убедитесь, что IP-адрес и порт указаны правильно, или выбран правильный COM-порт
- Проверьте настройки firewall, которые могут блокировать соединение
- Убедитесь, что другое программное обеспечение не использует одновременно соединение с устройством

### Журнал обмена данными

Используйте журнал обмена данными в нижней части приложения для диагностики проблем:
- Просматривайте отправляемые команды и полученные ответы
- Обратите внимание на различие между командами управления (не требуют подтверждения) и запросными (ожидают ответа)
- Проверяйте контрольные суммы команд и правильность формата
